                    b) $inc : {polje_iz_baze : + / - bro, polje_iz_baze : broj / "string", ....}
                        - povecaj polje_iz_baze za broj
                        - umanji polje_iz_baze za -broj

        2) model.updateOne({uslov}, {menjanje})
            - isto kao updateMany samo radi za prvog koji naidje sa zadatim uslovom
    
    *BRISANJE*:
        1) model.deleteOne / deleteMany({kriterijum})
            - brise prvog / sve sa zadatim kriterijumom
            - kriterijum izgleda ovako : { polje_iz_baze : NESTO , polje_iz_baze : NESTO, ......}
                Opcije za NESTO:
                    a) broj / "string"
                        -ako trazimo konkretan broj ili string
                    b) /^Pa/
                        - svi koji pocinju sa Pa
                    c) /ic$/
                        - svi koji se zavrsavaju na ic
                    d) /an/
                        -svi koji sadrze an
                    e) {objekat}
                        Opcije za objekat:
                            A) &gt: / &gte:
                                - veci / veci ili jednak
                            B) &lt: / &lte:
                                - manji / manji ili jednak
                            C) &ne:
                                - nije jednak
                            D) &in : [opcije]
